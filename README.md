# 📊 Análise de Dados da COVID-19 no Brasil

## 📌 Sobre o projeto

Este projeto apresenta uma análise exploratória dos dados da COVID-19 no Brasil, utilizando dados públicos do Ministério da Saúde.

O objetivo foi identificar padrões, comparar os estados brasileiros e analisar a evolução dos casos e óbitos ao longo do período estudado.

## 🎯 Objetivos

- Identificar os estados com maior número de casos acumulados.
- Identificar os estados com maior número de óbitos acumulados.
- Analisar a evolução dos casos ao longo do tempo.
- Comparar casos e óbitos entre os estados.
- Calcular a taxa de óbitos em relação aos casos.
- Criar visualizações para facilitar a interpretação dos dados.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Spyder

## 📈 Principais resultados

- São Paulo apresentou o maior número de casos acumulados.
- São Paulo apresentou o maior número de óbitos acumulados.
- Foram analisadas as variações de casos ao longo do período estudado.
- Foi calculada a taxa de óbitos em relação aos casos por estado.

## 📂 Arquivos do projeto

- `projeto_covid.py` — código utilizado para realizar a análise.
- `resultado_final_covid.csv` — tabela com os resultados finais.

## 📊 Análises realizadas

O projeto inclui análises de:

- Casos acumulados por estado.
- Óbitos acumulados por estado.
- Evolução temporal dos casos.
- Evolução dos óbitos.
- Taxa de óbitos por estado.

## 📚 Fonte dos dados

Os dados utilizados são provenientes do Ministério da Saúde e correspondem aos registros públicos da COVID-19 no Brasil.
